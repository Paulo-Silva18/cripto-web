Módulo Simétrico — DES (CBC + PKCS#7)

A chave informada é normalizada para 8 bytes (64 bits). O IV (vetor de inicialização) é gerado aleatoriamente a cada cifragem e vai embutido nos primeiros 8 bytes do arquivo cifrado.

1. Cifrar arquivo

2. Decifrar arquivo

Como comprovar a integridade

  1. Selecione uma imagem (.jpg/.png) ou PDF e cifre-a com uma chave.
  2. Baixe o arquivo .des gerado — repare que ele não abre mais como imagem/PDF (está cifrado).
  3. Envie esse mesmo arquivo .des no formulário de decifrar, usando a mesma chave.
  4. O arquivo original é reconstruído e deve abrir perfeitamente.
